# Android Application Source Code


This folder is reserved for the Android Studio project source code.


## Instructions

Upload the complete Android application project inside this folder.


The folder should contain the Android Studio project files, including:

- Source code
- Resources
- Layout files
- Gradle configuration files
- Required project dependencies

A typical repository structure should look like:

```text
Group-XX-Android-App

├── app/
│   └── Android Studio project source code
│
├── docs/
│   └── Project documentation files
│
├── README.md
│
└── CONTRIBUTION.md
```


## Important Notes

- Do not upload APK files only. The complete source code must be included.
- Ensure the project can be opened and built using Android Studio.
- Do not upload sensitive information such as API keys, passwords, or private credentials.
- Commit and push changes regularly during development.
